# 批量图片压缩（Windows）

双击 `dist\批量图片压缩.exe` 即可运行，无需安装 Python。适用于 64 位 Windows 10/11。

## 三种模式

| 模式 | 作用 | 参数 |
|---|---|---|
| 无损压缩 | 宽高不变，只减小文件体积 | 质量：低 30% / 中 50% / 高 65% / 超高 80%（默认） |
| 等比缩放 | 宽和高按同一比例缩小 | 1%～100%，画质 80% |
| 指定尺寸 | 输出指定的宽×高（不能大于原图） | 宽、高（像素），画质 80%；可勾选“保持原图比例（不拉伸）” |

三种模式都支持批量：把多张图片或整个文件夹（含子文件夹）拖进窗口，或点击“添加图片 / 添加文件夹”。

## 使用说明

- 原图不会被修改。结果默认保存到“图片\照片压缩”，可点“更改…”换位置；同名文件自动加 “(1)” 编号，不会覆盖。
- 输出格式默认“保持原格式”：JPG、PNG、WebP 保持不变；BMP、GIF、TIFF 改存为 JPG（带透明度的存为 PNG）。也可以统一输出为 JPG、PNG 或 WebP。
- PNG 是无损格式，在“无损压缩”模式下按真正的无损方式优化，画质不变但体积通常只能减小一点。想明显变小，可把输出格式选为 JPG 或 WebP。
- “无损压缩”时如果结果反而比原图大，会直接保留原图。
- 照片会按 EXIF 方向自动摆正；输出不含 EXIF（拍摄参数、GPS 等），保留 ICC 色彩配置。
- 快捷键：Ctrl+O 添加图片，Ctrl+Enter 开始，Delete 移除所选。双击某一行打开结果，右键有更多操作。
- 设置保存在 `%APPDATA%\批量图片压缩\settings.json`。

## 从源码构建

需要 Python 3.11 或更高版本。双击 `build.bat`：它会创建 `.venv`、安装 `requirements.txt` 中的依赖，再运行 `build.py` 生成 `dist\批量图片压缩.exe`。

## 测试

```bat
.venv\Scripts\python.exe -m unittest discover -s tests
.venv\Scripts\python.exe tests\visual_check.py          :: 在进程内用真实界面跑三种模式并截图，加 --dark 检查深色主题
.venv\Scripts\python.exe tests\e2e_exe.py               :: 打包后 exe 的冒烟检查
```

后两个脚本需要已登录的桌面会话；测试窗口会放到所有窗口的最底层，只截取本应用窗口，不会发送任何键盘或鼠标输入。
